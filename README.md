## Scripts
- `scripts/gbd_burden_analysis.R`
: Main disease burden estimation (DALY, YLL, YLD)
- `scripts/case_control_paf.R`
: Calculation of population attributable fractions (PAF)
- `scripts/joint_paf_sensitivity.R`
: Sensitivity analysis for joint risk-factor PAF
- `scripts/inequality_metrics.R`
: Health inequality metrics assessment
- `scripts/mapping_global.R`
: Global geographical mapping and visualization
- `scripts/bpc_forecast.R`
: Burden forecasting analysis
